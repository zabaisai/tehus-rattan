# Identidad aplicada al producto (CRM) — TAKTO

Ejemplos **originales** de TAKTO. No se copia la identidad visual ni las pantallas de Kommo ni de ningún otro producto. La marca de plataforma TAKTO no se mezcla con la identidad de empresas cliente.

## Pantallas (`svg/` + `png/`)
- `login` — panel de marca navy + formulario; botón primario navy.
- `sidebar-conversation` — shell con sidebar navy (acento naranja en activo), lista de conversaciones con chips de etapa, hilo tipo WhatsApp y panel de **oportunidad / siguiente paso**. Botón *Enviar* naranja con **texto navy**.
- `pipeline` — kanban con las seis etapas y sus colores `pipeline.*`.

## Principios reflejados
Cada pantalla propone el **siguiente paso**; el color de marca dirige y el naranja acentúa sin saturar; datos/montos en IBM Plex Mono.
